# Power BI Dashboard

## Diabetes Healthcare Decision Support System

This folder contains the **Power BI dashboard** developed for the Diabetes Healthcare Decision Support System.

The dashboard transforms the PostgreSQL analytical outputs into interactive visualizations for healthcare performance monitoring and decision support.

## Dashboard Focus Areas

The dashboard provides analysis across:

* Diabetes prevention and population health
* Diabetes risk factors
* Population risk segmentation
* Hospital operations
* Hospital readmissions
* Diabetes care quality
* Healthcare resource utilization
* Actionable healthcare recommendations

## Dashboard Pages

1. **Executive Summary**
2. **Diabetes Prevention & Risk Analysis**
3. **Population Risk Segmentation**
4. **Hospital Operations & Readmission**
5. **Diabetes Care Quality**
6. **Actionable Recommendations**

## Key KPIs

* Total hospital visits
* Diabetes prevalence
* Total readmissions
* Readmission rate
* High-priority patients
* Average length of stay
* Average diagnoses
* Average medications
* Insulin therapy rate
* HbA1c testing rate
